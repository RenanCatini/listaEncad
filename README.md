# Estruturas de Dados com Listas Encadeadas em C

Este repositório contém três implementações em C de estruturas de dados baseadas em listas encadeadas:

- `lista.c`: Implementação de uma lista encadeada comum (inserção, remoção, busca, etc.)
- `pilha.c`: Implementação de uma pilha usando lista encadeada (LIFO - Last In, First Out)
- `fila.c`: Implementação de uma fila usando lista encadeada (FIFO - First In, First Out)

## Compilação

Para compilar qualquer um dos arquivos individualmente, use o comando abaixo no terminal (substituindo `arquivo.c` pelo nome do arquivo desejado):

```bash
gcc -o executavel arquivo.c
